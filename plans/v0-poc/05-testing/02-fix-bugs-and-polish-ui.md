# Fix Bugs and Polish the UI

[Back to Execution Map](../EXECMAP.md)

## Goal

Improve the release after initial testing.

## Tasks

- Bug fixes
- UI cleanup
- Flow and state refinements

## Constraints

- Prioritize release-blocking bugs and obvious UI friction over speculative
  redesigns.
- Keep polish aligned with the approved v0 flows and wireframes.

## Exit Criteria

- The highest-priority bugs found during testing are addressed.
- The release candidate is materially cleaner and more stable than the initial
  test pass.
