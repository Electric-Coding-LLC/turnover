# Test Core Functionality

[Back to Execution Map](../EXECMAP.md)

## Goal

Validate that the main release features work correctly.

## Tasks

- Import behavior
- Totals and PR calculations
- Run history behavior
- Naming and tagging behavior

## Constraints

- Test against the actual v0 feature set instead of hypothetical future work.
- Keep verification focused on the user-visible flows and core calculations that
  could block release readiness.

## Exit Criteria

- The main import, totals, records, history, naming, and tagging flows have
  been exercised.
- The team has concrete confidence in the core feature set or a short list of
  defects to fix next.
