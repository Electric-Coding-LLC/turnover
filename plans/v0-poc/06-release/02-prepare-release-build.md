# Prepare the Release Build

[Back to Execution Map](../EXECMAP.md)

## Goal

Get the app ready for deployment.

## Tasks

- Release configuration
- Build preparation
- Packaging and release checks

## Constraints

- Keep release preparation focused on the actual v0 distribution path.
- Use release checks that match the supported build and runtime environment.

## Exit Criteria

- The app has a prepared release build with the required configuration and
  checks completed.
- The build is ready for the chosen deployment path.
