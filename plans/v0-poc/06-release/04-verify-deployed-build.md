# Verify the Deployed Build

[Back to Execution Map](../EXECMAP.md)

## Goal

Confirm that the deployed build meets the release goals.

## Tasks

- Post-deployment verification
- Final goal check
- Any release follow-up items

## Constraints

- Verify the deployed build against the actual v0 goals and support docs.
- Keep follow-up limited to concrete release issues rather than opening a new
  planning phase inside this step.

## Exit Criteria

- Post-deployment verification confirms whether the release goals were met.
- Any follow-up items are concrete enough to close the release cleanly or feed
  a new initiative.
