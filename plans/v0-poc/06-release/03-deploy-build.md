# Deploy the Build

[Back to Execution Map](../EXECMAP.md)

## Goal

Deliver the prepared build to its target environment.

## Tasks

- The distribution path
- The actual deployment step
- Any immediate deployment checks

## Constraints

- Follow the actual v0 deployment target instead of inventing extra release
  channels.
- Keep immediate checks limited to confirming the build arrived and is usable.

## Exit Criteria

- The prepared build has been delivered through the chosen distribution path.
- Immediate post-deployment checks show the build is available for use.
