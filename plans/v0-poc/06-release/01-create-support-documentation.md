# Create Support Documentation

[Back to Execution Map](../EXECMAP.md)

## Goal

Create the documentation needed to support the app after implementation.

## Tasks

- Setup and run instructions
- HealthKit permission notes
- Known limitations
- Testing and troubleshooting notes
- Release notes or change summary

## Constraints

- Keep support material aligned with the actual shipped behavior and known
  limits of v0.
- Document only the workflows and constraints users or testers need for this
  release.

## Exit Criteria

- The release has a support documentation set covering setup, permissions,
  limitations, testing, and troubleshooting.
- Release-facing docs describe the same product behavior the build actually
  ships.
