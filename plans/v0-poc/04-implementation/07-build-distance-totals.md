# Build Distance Totals

[Back to Execution Map](../EXECMAP.md)

## Goal

Implement the distance summary experience.

## Tasks

- Week totals
- Month totals
- Year-to-date totals
- Miles default and miles/kilometers toggle

## Constraints

- Respect the local calendar and Monday-start week rule defined for v0.
- Keep totals derived from normalized run data rather than separate stored
  aggregates.

## Exit Criteria

- The summary experience shows working week, month, and year-to-date totals.
- Unit handling matches the default miles behavior and the planned miles or
  kilometers toggle.
