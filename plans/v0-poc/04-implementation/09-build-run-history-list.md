# Build the Run History List

[Back to Execution Map](../EXECMAP.md)

## Goal

Implement the main run-browsing view.

## Tasks

- The run list layout
- Newest-first sorting
- The fields shown for each run
- Entry into run details

## Constraints

- Keep the run list aligned with the planned `Runs` screen instead of adding
  extra management surfaces.
- Preserve newest-first browsing and the minimum run fields defined in the
  design docs.

## Exit Criteria

- The app has a usable run history list with the required run fields in
  newest-first order.
- Users can open run details from the history list.
