# Import Eligible Outdoor Runs

[Back to Execution Map](../EXECMAP.md)

## Goal

Import only the run workouts that qualify for v0.

## Tasks

- Outdoor-run filtering rules
- Exclusion of manual and third-party runs
- Import of the core workout records needed by the app

## Constraints

- Apply the v0 eligibility rules consistently during import.
- Do not broaden the import path beyond Apple Health outdoor runs approved for
  this release.

## Exit Criteria

- The import flow reliably brings in only workouts that qualify for v0.
- The imported data set is suitable for storage and downstream feature work.
