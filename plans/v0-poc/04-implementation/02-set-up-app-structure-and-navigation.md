# Set Up the App Structure and Navigation

[Back to Execution Map](../EXECMAP.md)

## Goal

Create the app shell and screen structure.

## Tasks

- App entry structure
- Screen organization
- Navigation scaffolding

## Constraints

- Follow the defined architecture and navigation model instead of inventing new
  app shells.
- Keep the shell focused on the planned v0 screens and flows.

## Exit Criteria

- The app has a working shell with the planned screen entry points and
  navigation scaffolding.
- Feature work can proceed without revisiting the app-level structure.
