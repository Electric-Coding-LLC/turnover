# Build Personal Records

[Back to Execution Map](../EXECMAP.md)

## Goal

Implement the PR experience for the target distances.

## Tasks

- The supported PR distances
- Best-time and pace display
- PR extraction from longer runs
- Linking each PR to the underlying run

## Constraints

- Support only the target PR distances defined for v0.
- Keep PRs derived from eligible run data instead of introducing separate
  record storage.

## Exit Criteria

- The app can show PR results for the planned distances with time, pace, date,
  and linked run context.
- PR calculations include qualifying efforts extracted from longer runs.
