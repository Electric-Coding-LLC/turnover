# Add Run Naming

[Back to Execution Map](../EXECMAP.md)

## Goal

Allow custom names to be added to runs.

## Tasks

- Naming entry and editing
- Saving custom names
- Display of custom names in the app

## Constraints

- Keep naming as app-owned metadata attached to imported runs.
- Keep name editing close to run detail rather than creating a separate naming
  workflow.

## Exit Criteria

- Users can add and edit custom run names.
- Saved names appear in the appropriate detail and list surfaces.
