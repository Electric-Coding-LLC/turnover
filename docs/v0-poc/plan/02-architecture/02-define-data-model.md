# Define Data Model

## Goal

Define the data model that supports imported runs, app-owned metadata, and
derived calculations.

## Covers

- The core fields stored for imported runs
- Stable identifiers for mapping app data to imported workouts
- The structure for custom names and tags
- The data needed for totals, PRs, history, and filtering
- How imported data and app-owned data relate to each other

## Output

- A clear data model for the v0 build
